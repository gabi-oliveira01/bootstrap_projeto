## 📌 Sobre o Projeto
O **Paw & Care** é uma plataforma de uma ONG Animal voltada para a divulgação e o primeiro processo da adoção de animais de estimação resgatados. O objetivo do site é apresentar os pets disponíveis para adoção e permitir que interessados enviem pedidos de adoção, possiblitando maior alcance de candidatos para adoção.
